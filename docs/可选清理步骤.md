# 可选：删除「几乎不用」的历史文档

> **用途**：在 Git 已提交「文档重组基线」之后，若团队确认不需要备查，可按本页删除 `docs/archive/` 与 `文档整理方案.md`。  
> **原则**：先提交、再删；删前确认无同事仍依赖 archive 链接。

---

## 前置条件

- [ ] 当前分支工作区干净，或已把要做的改动都提交
- [ ] 已阅读 [README](../README.md)「文档怎么用」，确认日常只依赖 `docs/architecture` 等活跃文档
- [ ] 与团队同步：删除后仅从 **Git 历史** 恢复全文

---

## 第一步：提交基线（若尚未提交）

在项目根目录执行：

```powershell
cd d:\alijing\my\code\best_msc_ui

git status
git add -A
git commit -m "$(cat <<'EOF'
docs: 重组文档体系并迁移 Cursor 规则

- 新增 docs/、.cursor/rules、CHANGELOG、PR 模板与 MAINTENANCE
- 根目录冗长文档迁入 docs 或 archive；README 增加文档使用说明
- LoginForm 迁至 modules/components/auth；移除 .trae/rules 与 prompt.md
EOF
)"
```

> Windows PowerShell 若不支持 HEREDOC，可改用单行 message，或 `git commit -F commit-msg.txt`。

验证：

```powershell
git log -1 --oneline
git status   # 应为 nothing to commit, working tree clean
```

**建议打标签（可选）**：

```powershell
git tag -a docs-baseline-2026-05-27 -m "文档重组完成，删除 archive 前的基线"
```

---

## 第二步：删除 `docs/archive/` 内历史文件

### 2.1 建议删除列表

| 文件 | 原因 |
|------|------|
| `docs/archive/SUMMARY_REPORT.md` | 一次性梳理报告 |
| `docs/archive/CHANGELOG_DOCS.md` | 文档搬家日志；产品变更见根目录 CHANGELOG |
| `docs/archive/AUTH_CHECKLIST.md` | 鉴权实施清单（已完成） |
| `docs/archive/PROJECT_OVERVIEW.full.md` | 已由 `docs/architecture.md` 替代 |
| `docs/archive/AUTH_SCHEME.full.md` | 已由 `docs/auth.md` 替代（可选保留） |
| `docs/archive/README.md` | 索引文件，目录清空后一并删除 |

### 2.2 PowerShell 命令（推荐最小集：整目录删除）

```powershell
cd d:\alijing\my\code\best_msc_ui

Remove-Item -Recurse -Force .\docs\archive
```

若希望**只删过程文档、保留 AUTH_SCHEME.full**：

```powershell
Remove-Item .\docs\archive\SUMMARY_REPORT.md, .\docs\archive\CHANGELOG_DOCS.md, `
  .\docs\archive\AUTH_CHECKLIST.md, .\docs\archive\PROJECT_OVERVIEW.full.md -Force
# 保留 AUTH_SCHEME.full.md 时，仍需更新 docs/auth.md 中的链接（见第三步）
```

---

## 第三步：更新仍指向 archive 的链接

删除后全局搜索并修改：

```powershell
cd d:\alijing\my\code\best_msc_ui
git grep -n "docs/archive\|archive/"
```

### 必改文件（删除整个 archive 时）

| 文件 | 修改内容 |
|------|----------|
| [docs/auth.md](./auth.md) | 删除或改写首行「完整历史方案见 archive/AUTH_SCHEME.full.md」 |
| [CHANGELOG.md](../CHANGELOG.md) | 删除「文档体系历史见 docs/archive/CHANGELOG_DOCS.md」一句，或改为「见 Git 历史」 |
| [README.md](../README.md) | 文档索引表去掉「文档归档」行；「文档怎么用」折叠表里去掉 archive 行 |
| [docs/MAINTENANCE.md](./MAINTENANCE.md) | 季度检查中 archive 相关条目改为「已删除，仅 Git 历史」或删除该节 |
| [文档整理方案.md](../文档整理方案.md) | 若保留本文件：更新 archive 说明；若删除本文件见第四步 |

### `docs/auth.md` 示例（删除 full 版后）

将文首引用改为：

```markdown
> 实现细节以仓库内 `middleware/`、`utils/api.ts`、`stores/user.store.ts` 为准。
```

## 第四步（可选）：删除根目录 `文档整理方案.md`

1. 将其中 **SSOT 表**、**目标目录结构** 合并进 [MAINTENANCE.md](./MAINTENANCE.md)（若尚未包含）。
2. 修改引用：
   - [.github/pull_request_template.md](../.github/pull_request_template.md)：`文档整理方案` → `docs/MAINTENANCE.md`
   - [docs/architecture.md](./architecture.md)：去掉「文档整理方案」链接或改为 MAINTENANCE
3. 删除文件：

```powershell
Remove-Item .\文档整理方案.md -Force
```

4. README「文档索引」去掉「文档整理方案」一行。

---

## 第五步：提交删除

```powershell
git add -A
git status
git commit -m "docs: 移除 docs/archive 历史文档并更新链接"
```

```powershell
git checkout docs-baseline-2026-05-27 -- docs/archive/AUTH_SCHEME.full.md
```
